## "项目内容 / 承担工作"两段式（校招简历常用格式，可直接粘贴）

**InsightAgent：基于 LangGraph 与确定性守卫的企业数据问答 Agent（个人项目，开源）** 　2025.XX–2026.XX

➢ **项目内容**：面向企业临时取数场景——业务人员的长尾查询需提工单排队等数据分析师、
仪表盘只覆盖预设问题——构建对话式数据问答 Agent，解决 LLM 生成 SQL 落地中的三个核心
问题：模型输出不可信（误改库/越权查询/危险代码）、回答存在数字幻觉、效果无法量化证明；
项目覆盖从 Schema 检索、SQL 生成、守卫执行、错误自纠、防幻觉校验、图表生成到评测复盘
的完整闭环，目标是在只读安全、成本预算、全程可审计的约束下，交付可信、可复现、可解释
的自然语言取数能力。

➢ **承担工作**：独立完成整体设计与全部实现。基于 LangGraph 将主流程建模为六节点状态机
（生成/守卫执行/修复/图表/归纳/降级），实现结构化错误分类驱动的 Reason-Act-Observe
自纠错内环（按错误类型定向重写、重复 SQL 检测、轮次上限与 token/金额双预算熔断）；
构建安全纵深：sqlglot AST 级 SQL 守卫（单条 SELECT、表白名单、强制 LIMIT）、SQLite
三重只读（mode=ro/query_only/authorizer）与 MySQL/PG 只读账号接入、图表代码 Docker
断网沙箱/子进程 rlimit 限额；设计基于数字出处匹配的防幻觉校验器（舍入感知、千分位/
百分号/万亿单位、问题与 SQL 计入出处、违规先重写再降级两段式）；实现业务字典/few-shot
例句/跨会话用户记忆三层知识的 BM25(中文分词)+RRF 检索注入，注入明细逐次可观测；搭建
评测体系：BIRD 公开基准适配与固定子集抽取、236 例自建业务评测集（dev/holdout 切分、
gold 逐条执行校验）、EX 执行准确率、gold 回放基建自检、Wilson 95% 置信区间与 McNemar
显著性检验、消融对比报告（基于失败模式分析定向修复口径注入与输出纪律，EX 由基线
93.3% 提升至 97.8%，+4.5pp，两轮 95% CI 不重叠、按题配对翻转 5:0）；工程化交付 FastAPI SSE 流式服务、
Vue3 前端、结果缓存、Prometheus/Grafana 监控、Langfuse 链路追踪、Docker 一键部署，
249 例离线测试接入 CI。

在只读守卫下执行、失败自动修复，最后出图表和结论，且结论里每个数字都经过与查询结果的
自动比对。整个项目我最看重评测：BIRD 公开基准加 236 条自建业务集，数字带置信区间、
每次改动有回归 CI。业务集基线 EX 93.3%，我做了一轮失败模式分析——最大失败类是模型
自行给统计加订单状态过滤——用业务字典补口径定义、提示词加输出纪律定向修复，一轮提到
97.8%，两轮置信区间不重叠、按题翻转 5 比 0。配对检验 p=0.0625 没到 0.05，我如实
引用区间而不宣称显著——评测的每个数字我都能守住。"
